# Démarrer Codex en trois actions

1. Dézipper ce paquet : il contient le code **réel** de Companion V0.1 plus les instructions de V1.
2. Créer un dépôt Git privé et importer **le contenu du dossier `PixelProwlers-LIBRE-Companion` à la racine** du dépôt. Activer les Actions GitHub si utilisées.
3. Ouvrir ce dépôt dans Codex et coller le contenu de `PROMPT_CODEX.md`. Les consignes durables pour l'agent sont dans `AGENTS.md`.

Le paquet **ne contient pas une V1 déjà développée** : c'est un dossier de mission permettant à Codex de développer, tester et préparer une V1 sans inventer l'architecture.

Ne publier aucun installateur en production tant que les tests OEM réels sur HP EliteBook n'ont pas été validés. Git privé recommandé jusqu'à revue des licences et de la sécurité.
