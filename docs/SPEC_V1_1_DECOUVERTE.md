# Companion 1.1 — découverte de Linux Mint Cinnamon

## Objectif
Un premier parcours « Retrouver mes habitudes » qui permet une exploration libre ou une visite guidée facultative.

## Contenu livré
- Illustration schématique locale du bureau Cinnamon, explicitement non contractuelle.
- Huit sujets : menu, panneau, fichiers, paramètres, indicateurs, applications, mises à jour, sous le capot.
- Quatre profondeurs par sujet : découvrir, comprendre, utiliser, approfondir.
- Visite guidée de six sujets réutilisant exactement les mêmes contenus.
- Recherche locale par termes usuels et correspondances Windows.
- Aucune action système nouvelle, aucun accès réseau, aucune collecte supplémentaire.

## Limites
- Les captures fidèles de Cinnamon ne sont pas incluses : le bureau est une illustration pédagogique originale, non une simulation exacte.
- Les exercices se réalisent manuellement dans l'environnement réel et ne sont pas suivis ou vérifiés automatiquement.
- Les contenus supposent Linux Mint Cinnamon et devront être vérifiés sur la version OEM effectivement livrée.
- Aucune modification de la configuration système et aucune installation automatique n'est déclenchée par ce parcours.
- La V1.1 conserve les modules de configuration 0.1.0 et leur mécanisme d'état.

## Validation requise
Tester sur Linux Mint Cinnamon : navigation clavier, GTK/WebKit, affichages desktop et petit écran, commandes du système mentionnées, parcours sans connexion, paquet Debian et installation réelle.
